# Contributing

Contributions are welcome once the public repository is available.

- Keep changes focused and add tests.
- Preserve the security/privacy invariants in `AGENTS.md`.
- Do not include real email or deployment secrets in tests/issues.
- Update documentation for operational changes.
- Run relevant tests before submitting a pull request.
- Disclose substantial AI assistance when it materially generated or
  transformed code.
- Only contribute material you have the right to license under MIT.
